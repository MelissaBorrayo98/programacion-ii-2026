# Calculadora de Edad

## Descripción
Programa en Java que calcula la edad aproximada, edad en meses y determina si una persona es mayor de edad.

## Datos Solicitados
- Nombre completo
- Carné
- Año de nacimiento
- Año actual

## Cálculos Realizados
- Edad aproximada: año actual - año de nacimiento
- Edad en meses: edad aproximada * 12
- Mayoría de edad: comparación edad >= 18

## Instrucciones para Ejecutar
1. Abrir en IntelliJ IDEA
2. Ejecutar CalculadoraEdad
3. Ingresar datos solicitados
4. Ver resultados
