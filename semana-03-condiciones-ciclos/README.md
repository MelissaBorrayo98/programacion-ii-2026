# Tarea II: Condiciones y Ciclos

## Descripción
Programa en Java desarrollado en consola que implementa un menú interactivo mediante las estructuras do-while y switch para resolver 5 ejercicios lógicos utilizando estructuras condicionales y ciclos de repetición (for, while).

---

## Funcionalidades del Menú

* **1. Generar secuencia personalizada:** Utiliza ciclos for y while para generar secuencias numéricas según la preferencia del usuario.
* **2. Conteo regresivo:** Realiza un conteo descendente desde un número inicial (entre 10 y 50) e imprime "¡Despegue!".
* **3. Analizar números:** Utiliza un ciclo while con break y continue para contar números positivos, negativos e ignorar múltiplos de 5 en la suma.
* **4. Dibujar pirámide:** Emplea ciclos for anidados para construir una figura con asteriscos basada en la altura ingresada.
* **5. Validar palabra secreta:** Utiliza los métodos .trim() y .equalsIgnoreCase() para validar la palabra "Guatemala" ignorando mayúsculas, minúsculas o espacios adicionales.
* **6. Salir:** Finaliza la ejecución del programa.
