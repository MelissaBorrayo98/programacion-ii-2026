# Calculadora de Áreas de Figuras Geométricas

## Breve descripción
Aplicación de consola desarrollada en Java que demuestra los principios de la Programación Orientada a Objetos (POO): abstracción, encapsulamiento, herencia, sobrescritura y polimorfismo para calcular el área de distintas figuras geométricas.

## Figuras implementadas
* Círculo
* Rectángulo
* Triángulo

## Instrucciones para ejecutar el programa
1. Asegúrate de tener instalado el Java Development Kit (JDK) en tu equipo.
2. Compila todos los archivos fuente desde la carpeta raíz o `src/`:
   ```bash
   javac src/*.java
